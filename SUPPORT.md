# Support

- **A rule fired and you disagree with it** — the message links to
  `docs/rules/<id>.md`, which states the reasoning and shows the intended
  alternative. If it is wrong for your case, open an issue with the code that
  triggered it; a false positive is a rule bug.
- **An installed source contradicts the constitution** — that is the most useful
  issue you can file. See
  [CONTRIBUTING.md](CONTRIBUTING.md#reporting-a-conflict-between-sources).
- **Questions and ideas** — GitHub Discussions.
- **Bugs** — GitHub Issues, with the rule id and a minimal reproduction.

This is a young project maintained in the open. There is no support SLA.
