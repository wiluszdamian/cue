# Cue landing page

A single static page, `index.html`, with inline CSS and JS. No build step.

Preview it locally:

```bash
npx serve site
```

Deploy by pointing any static host (GitHub Pages, Cloudflare Pages, Netlify) at
this folder.

## Logo

`brand/` holds the Cue logo as SVG: the full lockup (`cue-logo-*.svg`) and the
mark alone (`cue-mark-*.svg`), each in a light-mode and a dark-mode version.
